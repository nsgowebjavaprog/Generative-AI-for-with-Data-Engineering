## ------

1. **BOW (2000)** → Counts words.
   Example: `"I love AI"` → counts **I = 1, love = 1, AI = 1**

2. **Word2Vec (2013)** → Understands **word similarity**.
   Example: **King** and **Queen** are related words.

3. **Attention (2017)** → Understands **which words are important**.
   Example: `"The boy ate because he was hungry"` → understands **he = boy**.

4. **GPT / BERT / T5 (Now)** → Understands **context and can generate text**.
   Example: You ask **"What is AI?"** → GPT can generate an answer.
